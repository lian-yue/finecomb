# 12 Files, archives and decoder side effects

| Pattern | Historical cases | What to look for | Where it lands |
| --- | --- | --- | --- |
| **Path traversal in archive entries** | Zip Slip (2018); Python tarfile (CVE-2007-4559, unfixed for more than ten years) | The final path and link target of every entry during extraction | [4.8](../specialties/4.8-file-systems-and-paths.md) ("Archive extraction") |
| **Upload means execution** | vCenter (CVE-2021-21972); FatPipe (CVE-2021-27860) | Whether uploaded files can land in locations that are executable or that the server interprets | [4.8](../specialties/4.8-file-systems-and-paths.md) ("Uploads and foreign files") |
| Case-insensitive file systems | Git (CVE-2014-9390, `.GIT` overwrote the hooks in `.git`) | Whether protections that rely on case stop working on case-insensitive file systems | [38](../dimensions/38-portability-and-build-context.md), [4.8](../specialties/4.8-file-systems-and-paths.md) |
| **Decoders run external commands** | ImageTragick (CVE-2016-3714); GitLab parsing DjVu through ExifTool (CVE-2021-22205) | Whether image and document processing libraries call external programs or interpret embedded instructions | [4.22](../specialties/4.22-subprocesses-dynamic-execution-and-decoder-side-effects.md) ("Decoder side effects") |
| Debug files shipped with dependencies exposed externally | ownCloud (CVE-2023-49103, a test file shipped with a third-party library printed phpinfo, leaking secrets in environment variables) | Whether dependency examples, tests and debug pages in the deployment package can be reached from outside | [36](../dimensions/36-supply-chain-and-artifact-integrity.md) ("Extra files shipped with dependencies") |
| **The origin mark is not passed on with the file** | 7-Zip (CVE-2025-0411, the download origin mark was not passed on when extracting nested archives); Windows (CVE-2022-41091, CVE-2024-21412 and other origin mark and SmartScreen bypasses); macOS "Achilles" (CVE-2022-42821, a restrictive ACL kept the quarantine attribute from being written) | Whether programs that handle foreign files keep the origin mark after extracting, copying or converting; whether they still let the file through when writing the mark fails | [4.35](../specialties/4.35-client-apps-extensions-and-auto-update.md) ("Download origin marks"), [4.8](../specialties/4.8-file-systems-and-paths.md) ("Archive extraction") |
| Searching upward finds someone else's configuration | Git for Windows (CVE-2022-24765, a `.git` placed under `C:\`, which many users can write, is read by other users running Git in a subdirectory, and the configuration in it is executed) | Whether the configuration search range crosses a trust boundary; whether trust is confirmed before opening someone else's directory | [4.15](../specialties/4.15-command-line-and-process-entry-points.md) ("Configuration discovery") |
