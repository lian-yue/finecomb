# 14 Supply chain, build and release

| Pattern | Historical cases | What to look for | Where it lands |
| --- | --- | --- | --- |
| **Maintainer takeover and build script backdoors** | xz utils (CVE-2024-3094, after a long effort to gain maintainer rights, a backdoor was hidden in binary test files and extracted and injected by the build script) | Whether binaries and test files in the repository are read and executed by build scripts; whether release packages match the repository contents; whether maintainer rights changed recently | [36](../dimensions/36-supply-chain-and-artifact-integrity.md) ("Binaries and archives in the repository", "Maintenance status") |
| Compromised build systems | SolarWinds (2020, a backdoor was injected during the build) | Isolation and integrity of the build environment; whether outputs can be reproduced | [36](../dimensions/36-supply-chain-and-artifact-integrity.md) ("Build and release permissions", "Reproducible builds") |
| Publishing accounts stolen or handed over | ua-parser-js (2021, the publishing account was stolen); event-stream (2018, maintainer rights were handed to an attacker) | Whether a dependency's publishers and maintainer rights changed recently | [36](../dimensions/36-supply-chain-and-artifact-integrity.md) ("Maintenance status") |
| **Referenced external actions repointed** | tj-actions/changed-files (CVE-2025-30066, tags were repointed to a malicious commit, leaking CI secrets) | Whether external actions and images that workflows reference are pinned to immutable digests | [4.33](../specialties/4.33-build-scripts-ci-and-infrastructure-as-code.md) ("Pinning third-party steps") |
| Third-party script domains change hands | polyfill.io (2024, after the domain changed hands it served malicious code to many websites) | The sources and integrity checks of external scripts that pages reference | [4.18](../specialties/4.18-user-interfaces-and-accessibility.md) ("Third-party scripts") |
| Download-and-run scripts tampered with | Codecov (2021, the upload script was tampered with and stole CI environment variables) | Scripts that the build downloads and runs directly without verification | [4.33](../specialties/4.33-build-scripts-ci-and-infrastructure-as-code.md), [36](../dimensions/36-supply-chain-and-artifact-integrity.md) |
| Dependency confusion | Dependency confusion demonstrations against many companies in 2021 | Whether private package names can be resolved from public registries | [36](../dimensions/36-supply-chain-and-artifact-integrity.md) ("Dependency confusion") |
| **Stale dependencies** | Zoho ManageEngine (CVE-2022-47966, used an XML signature library that had not been updated for years) | Whether dependency versions lag behind security fixes | [36](../dimensions/36-supply-chain-and-artifact-integrity.md) ("Security fix versions", "Support lifetime") |
| **Old versions with valid signatures installed again** | BlackLotus (the vulnerable boot loader of CVE-2022-21894 was still not added to the revocation list after the fix, and was installed again to bypass Secure Boot); Windows Downdate (CVE-2024-21302, CVE-2024-38202, rolling patched system components back to old versions); bring-your-own-vulnerable-driver (CVE-2021-21551, CVE-2019-16098) | A signature only proves origin: whether old signed components can still load, what prevents downgrades, and whether revocation has kept up | [4.36](../specialties/4.36-embedded-firmware-and-real-time-constraints.md) ("Anti-rollback"), [4.35](../specialties/4.35-client-apps-extensions-and-auto-update.md) ("Auto-update"), [4.48](../specialties/4.48-kernel-drivers-device-emulation-and-virtualization.md) ("Signing and block lists") |
| Maintainer email domain expired | PyPI ctx (2022, the attacker registered the expired domain of the maintainer's email, reset the password, and published versions that stole environment variables) | Recovery channels for maintainer accounts; whether referenced names can expire and change hands | [36](../dimensions/36-supply-chain-and-artifact-integrity.md) ("Names re-registered after they lapse", "Maintenance status") |
| **Incomplete fixes or regressions** | The first Log4j fix was bypassed (CVE-2021-45046); regreSSHion is a regression of a vulnerability from 18 years earlier | Whether the fix only blocks the sample input; whether fixed issues have regression tests | [Part VI: Fix discipline](../report.md#part-vi-fix-discipline), [41](../dimensions/41-test-quality.md) ("Regression protection for security fixes") |
