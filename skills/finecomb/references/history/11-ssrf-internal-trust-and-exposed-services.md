# 11 SSRF, internal trust and exposed services

| Pattern | Historical cases | What to look for | Where it lands |
| --- | --- | --- | --- |
| **SSRF reaching cloud metadata** | Capital One 2019 | Whether outbound requests can reach metadata addresses and obtain credentials | [4.21](../specialties/4.21-outbound-requests-and-server-side-request-forgery.md) |
| **SSRF chained to internal high-privilege interfaces** | Exchange ProxyLogon (CVE-2021-26855), ProxyShell (CVE-2021-34473), CVE-2022-41040; F5 iControl (CVE-2021-22986) | Whether the frontend proxy can reach backend admin interfaces with an internal identity; whether the backend treats internal sources as authenticated | [4.21](../specialties/4.21-outbound-requests-and-server-side-request-forgery.md), [34](../dimensions/34-runtime-environment-and-deployment-contract.md) ("Network and management plane") |
| Internal protocols exposed externally | Tomcat Ghostcat (CVE-2020-1938, AJP port exposed externally) | Whether ports for protocols meant only for internal use are bound to external interfaces | [34](../dimensions/34-runtime-environment-and-deployment-contract.md) |
| Databases and admin interfaces with no authentication | Redis, Elasticsearch, MongoDB, the Docker API and kubelet on the public internet | Whether services listen on all interfaces by default with no authentication | [34](../dimensions/34-runtime-environment-and-deployment-contract.md), [27](../dimensions/27-security-and-trust-boundaries.md) ("Hardening") |
| **Dangling DNS and subdomain takeover** | Many subdomains pointing to deleted cloud resources were claimed by others | Whether the lifecycles of DNS records and cloud resources stay in sync | [Targets that are not source code: live services](../targets/live-services.md), [4.33](../specialties/4.33-build-scripts-ci-and-infrastructure-as-code.md) |
| **Local development tools driven by web pages** | MCP Inspector (CVE-2025-49596, the local proxy did not authenticate, and a web page could make it start any command); Zoom (CVE-2019-13450, a local web server let any website pull the user into a meeting with the camera on) | Whether services listening only on the local machine check the origin, the Host and the caller's identity | [4.14](../specialties/4.14-server-request-handling-and-middleware.md) ("Services listening only on the local machine"), [4.35](../specialties/4.35-client-apps-extensions-and-auto-update.md) ("Local control plane") |
