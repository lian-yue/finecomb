# 17 Clients, browsers and sandboxes

| Pattern | Historical cases | What to look for | Where it lands |
| --- | --- | --- | --- |
| **Sandbox escape through exception objects** | vm2 (CVE-2023-29017 and others, the host's exception and error handling hooks handed host objects to code in the sandbox) | Whether exceptions, error stacks, callback arguments and proxy objects can carry host references into the sandbox | [4.27](../specialties/4.27-interpreters-compilers-and-virtual-machines.md) ("Host boundary") |
| Desktop frameworks expose local capabilities | In Electron apps with Node integration turned on and context isolation turned off, a single XSS becomes code execution | Which local interfaces embedded web content can call | [4.35](../specialties/4.35-client-apps-extensions-and-auto-update.md) ("Embedded web content") |
| **Update channels hijacked** | NotPetya (2017, spread through the update channel of accounting software) | Whether auto-update verifies signatures, and what happens when the update server is taken over | [4.35](../specialties/4.35-client-apps-extensions-and-auto-update.md) ("Auto-update") |
| Sanitizer and browser parsing differentials | HTML sanitizer bypasses that keep reappearing (mutation XSS) | Whether sanitized markup becomes a different structure when the browser parses it again | [4.18](../specialties/4.18-user-interfaces-and-accessibility.md) ("Client-side security") |
| DOM clobbering | webpack (CVE-2024-43788, an element on the page with a specific `name` changed the script path the runtime derived, leading to XSS) | Whether globals and `document` properties that frontend code reads can be overwritten by page elements | [4.18](../specialties/4.18-user-interfaces-and-accessibility.md) ("DOM clobbering") |
| Handing an address from the peer to the system to open | mcp-remote (CVE-2025-6514, an authorization address returned by a malicious MCP server was handed to the system to open, and on Windows a command ran through PowerShell) | The protocol restrictions and invocation method used before opening external addresses | [4.35](../specialties/4.35-client-apps-extensions-and-auto-update.md) ("Addresses handed to the system to open"), [4.22](../specialties/4.22-subprocesses-dynamic-execution-and-decoder-side-effects.md) ("Invocation method") |
| Parameters from external invocation become program switches | Electron (CVE-2018-1000006, when invoked through a custom protocol on Windows, the address content became command-line switches of the program, allowing commands to run) | How parameters that a protocol handler receives get into the command line | [4.35](../specialties/4.35-client-apps-extensions-and-auto-update.md) ("External invocation") |
| **High-privilege components do not check the caller** | Samsung clipboard provider (CVE-2021-25337, ran as system with no access control, so any app could read and write files; exploited in the wild by commercial spyware) | Whether exported components that run with high privileges check the caller | [4.49](../specialties/4.49-mobile-app-components-and-inter-process-communication.md) ("Exported components") |
| Deep links make embedded web views load any address | TikTok Android (CVE-2022-28799, a deep link bypassed validation and made the WebView load any page, which then called more than 70 native bridge methods to take over the account) | Validation of deep link parameters before they reach a WebView; the native bridge's restrictions on origin | [4.49](../specialties/4.49-mobile-app-components-and-inter-process-communication.md) ("Deep links and web views") |
| **Model output calls out automatically when rendered** | M365 Copilot EchoLeak (CVE-2025-32711, injected instructions in an email made the answer include a reference-style image; when it was rendered, data was sent out through a Teams address that the content security policy allowed, with zero clicks) | Whether the places that render model output request external addresses automatically | [4.26](../specialties/4.26-llms-and-tool-calling.md) ("Rendered output that calls out") |
| **Agents rewrite their own approval settings** | GitHub Copilot (CVE-2025-53773, injected instructions made the agent turn on `chat.tools.autoApprove` in `.vscode/settings.json`, after which it ran commands without asking) | Whether files the agent can write contain configuration that decides its own permissions | [4.26](../specialties/4.26-llms-and-tool-calling.md) ("Rewriting its own constraints") |
| Tool description poisoning and changes after approval | MCP tool poisoning, swapping descriptions after approval, and same-name shadowing, published by Invariant Labs in 2025 | The origin of tool definitions, change detection and re-approval | [4.26](../specialties/4.26-llms-and-tool-calling.md) ("Tool definitions and their origin") |
