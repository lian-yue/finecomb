# 3 Commands, file names and environments assembled later

| Pattern | Historical cases | What to look for | Where it lands |
| --- | --- | --- | --- |
| **External data is stored first, then spliced into a command elsewhere** | PAN-OS (CVE-2024-3400, a value in the session cookie became a file name, which a telemetry script later spliced into a shell command); Barracuda ESG (CVE-2023-2868, file names inside a tar archive attached to an email entered a command) | After an external value is written as a file name, log field or configuration item, whether another component splices it into a command or script | [27](../dimensions/27-security-and-trust-boundaries.md) ("Second-order use"), [4.22](../specialties/4.22-subprocesses-dynamic-execution-and-decoder-side-effects.md) |
| Environment variables treated as code | Shellshock (CVE-2014-6271, while parsing a function definition in an environment variable, bash ran the commands that followed it) | Whether external input can become an environment variable of a subprocess; whether an interpreter interprets environment variable contents | [4.22](../specialties/4.22-subprocesses-dynamic-execution-and-decoder-side-effects.md) |
| **External input rewrites runtime configuration** | Juniper (CVE-2023-36844, CVE-2023-36845, PHP environment variables set over HTTP change the interpreter's behavior) | Whether a request can set environment variables and configuration paths that an interpreter, loader or framework reads | [4.22](../specialties/4.22-subprocesses-dynamic-execution-and-decoder-side-effects.md), [32](../dimensions/32-configuration-and-defaults.md) |
| Command injection in device management interfaces | Cisco IOS XE (CVE-2023-20273); many routers, cameras and VPN devices | Web admin pages that splice parameters into system commands | [4.22](../specialties/4.22-subprocesses-dynamic-execution-and-decoder-side-effects.md), [Targets that are not source code: firmware](../targets/firmware-and-device-images.md) |
| **Conversion before execution rewrites already validated arguments** | PHP-CGI (CVE-2024-4577, Windows character set best-fit mapping turns a soft hyphen into `-`, and the argument becomes a PHP option); BatBadBut (Rust CVE-2024-24576, Node.js CVE-2024-27980, batch files called with an argument array are still reparsed by `cmd.exe`) | After arguments and paths are validated, whether they still pass through character set conversion, command-line reassembly or another parser | [4.22](../specialties/4.22-subprocesses-dynamic-execution-and-decoder-side-effects.md) ("Windows command-line reassembly", "Character set conversion rewriting arguments"), [27](../dimensions/27-security-and-trust-boundaries.md) ("Input validation") |
