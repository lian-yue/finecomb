# 13 Containers, kernels and privilege

| Pattern | Historical cases | What to look for | Where it lands |
| --- | --- | --- | --- |
| **Descriptors leak into containers** | runc Leaky Vessels (CVE-2024-21626, a leaked host descriptor was used as the working directory) | Whether descriptors that should not be inherited are closed before creating a subprocess or container; whether, after entering the container, the working directory is confirmed to really be inside the container | [4.30](../specialties/4.30-os-interfaces-system-calls-and-descriptors.md) ("Blocking mode and inheritance") |
| Rewriting a host program from inside a container | runc (CVE-2019-5736, overwriting the host's runc through `/proc/self/exe`) | Whether a container can write files on the host that privileged processes execute | [34](../dimensions/34-runtime-environment-and-deployment-contract.md) ("Runtime identity and isolation"), [4.33](../specialties/4.33-build-scripts-ci-and-infrastructure-as-code.md) |
| Permissions carried over after a connection upgrade | Kubernetes (CVE-2018-1002105, the upgraded connection bypassed authorization) | Whether every request after a protocol upgrade or after a long-lived connection is set up is still authorized | [4.14](../specialties/4.14-server-request-handling-and-middleware.md) ("WebSocket and long-lived connections") |
| Low-privilege callers invoke high-privilege operations | PrintNightmare (CVE-2021-34527, ordinary users installed drivers through the print service) | Whether operations that privileged services expose check the caller's permissions | [28](../dimensions/28-authorization-and-access-control.md) ("Vertical privilege escalation") |
| **Protocol handlers invoked by documents or web pages** | Follina (CVE-2022-30190, a document invoked a diagnostic tool through the `ms-msdt:` protocol and ran code) | Whether custom protocols and system handlers can be triggered by external content with parameters passed in | [4.35](../specialties/4.35-client-apps-extensions-and-auto-update.md) ("External invocation") |
| Speculative execution side channels | Spectre (CVE-2017-5753), Meltdown (CVE-2017-5754) | Whether environments that run untrusted code can get high-precision timers | [4.27](../specialties/4.27-interpreters-compilers-and-virtual-machines.md) ("Timer precision and side channels") |
| Privileged attributes kept when copying | OverlayFS (CVE-2023-0386, when a setuid file whose owner has no mapping in the user namespace was copied to the upper layer, the setuid bit and the owner were kept, letting ordinary users escalate privileges) | Whether privileged attributes are stripped when copying, extracting or mounting; whether boundary values fall into a special case that "neither reports an error nor strips" | [27](../dimensions/27-security-and-trust-boundaries.md) ("Attributes carried across boundaries"), [4.8](../specialties/4.8-file-systems-and-paths.md) |
| **Privileged services operate on files in user-writable locations** | Windows BITS (CVE-2020-0787); AppX deployment service (CVE-2019-0841, a hard link made the service change the permissions of system files) | For every path a privileged process touches, whether any directory along it can be controlled by a low-privilege user | [4.47](../specialties/4.47-local-privileged-components-and-local-privilege-escalation.md) ("File operations in low-privilege writable locations"), [4.8](../specialties/4.8-file-systems-and-paths.md) ("Links and replacement after check") |
| Callers identified by process ID | F-Secure SAFE for macOS (CVE-2020-14977, an XPC service identified clients by process ID, and privileged commands ran after a process ID was reused) | How local inter-process interfaces authenticate callers | [4.47](../specialties/4.47-local-privileged-components-and-local-privilege-escalation.md) ("Caller identity") |
| Privileged components trust the caller's environment | macOS TCC (CVE-2020-9934, tccd located the authorization database from `$HOME`; changing `HOME` swapped in a database the caller wrote) | Where the path comes from when a privileged component locates security data | [4.47](../specialties/4.47-local-privileged-components-and-local-privilege-escalation.md) ("Caller-controlled environment") |
| Apps with permissions allow library injection | Microsoft Teams and Outlook for macOS (CVE-2024-42004, CVE-2024-42220, injected libraries could borrow the system permissions those apps already had) | Whether programs holding sensitive permissions enable library validation, and whether they carry entitlements that allow injection | [4.47](../specialties/4.47-local-privileged-components-and-local-privilege-escalation.md) ("Injection that borrows granted permissions") |
| Privileged execution of scripts that low-privilege users can write | VMware Workspace ONE Access (CVE-2022-22960, improper permissions on support scripts let local users escalate to root) | Write permissions on the files and directories of scripts that sudo rules, scheduled tasks and services call | [4.47](../specialties/4.47-local-privileged-components-and-local-privilege-escalation.md) ("Executable paths and load order") |
| **Drivers hand dangerous capabilities to any user** | Dell dbutil (CVE-2021-21551, insufficient access control); MSI RTCore64 (CVE-2019-16098, any user could read and write memory, I/O ports and MSRs; the signature is still valid, so it is often brought to other systems to exploit) | Caller checks on control codes; whether arbitrary read and write primitives are exposed | [4.48](../specialties/4.48-kernel-drivers-device-emulation-and-virtualization.md) ("Access control on device entry points", "Dangerous primitives") |
| GPU mappings still usable after free or permission downgrade | Arm Mali (CVE-2022-22706, ordinary users got write access to read-only pages; CVE-2023-4211, access to freed GPU memory), both exploited in the wild | Whether revoking mappings stays in sync with freeing pages and changing permissions | [4.48](../specialties/4.48-kernel-drivers-device-emulation-and-virtualization.md) ("Mapping lifetime and permissions") |
| Check and use separated in device emulation | VMware ESXi (CVE-2025-22224, a race between check and use caused an out-of-bounds write, escaping from the virtual machine to the host process); QEMU VENOM (CVE-2015-3456, out-of-bounds write in the floppy disk controller) | Whether guest-controlled values are read only once, and validated before use | [4.48](../specialties/4.48-kernel-drivers-device-emulation-and-virtualization.md) ("Guest-controlled device emulation"), [4.30](../specialties/4.30-os-interfaces-system-calls-and-descriptors.md) ("Reading untrusted memory twice") |
