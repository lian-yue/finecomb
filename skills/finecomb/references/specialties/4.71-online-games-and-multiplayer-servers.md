# 4.71 Online games and multiplayer servers

Applies to: game servers, matchmaking and lobbies, in-game economies, stores and trading, and the chat and user content inside games. Apply your own knowledge of the specific engine, network model and game genre to each row. For the client side see [targets: game clients](../targets/game-clients-and-anti-cheat.md).

| Checkpoint | What counts as a problem |
| --- | --- |
| **Client-reported state** | The server accepts position, movement, hits, damage, cooldowns, match results or scores from the client without checking them against its own state and physical limits (see [targets: game clients](../targets/game-clients-and-anti-cheat.md) ("The client has the final say")) |
| **Duplication and conservation** | Items or currency are created twice when trades, crafting, mail, drops or transfers are retried, cut off by a disconnect or server crash, or run at the same time; no ledger or reconciliation shows that the total grew (see [facets](../facets.md) "Conservation and invariants") |
| **Trading and marketplace fraud** | Trades are not atomic, so one side can change the offer after the other side accepted; stolen accounts, chargebacks and real-money trading turn into laundering through items or currency; market prices and fees can be manipulated (see [46](../dimensions/46-abuse-and-fraud-resistance.md) ("Fraud in value flows")) |
| Stores and rewards | Purchases, rewards and random drops are granted from client claims or receipts the server did not verify, or granted twice on retries (see [targets: game clients](../targets/game-clients-and-anti-cheat.md) ("In-app purchases and rewards")) |
| Matchmaking and lobbies | Players pick opponents or teams they should not get, join and leave to game ratings, rankings or rewards, or enter private lobbies and matches without an invitation; a lobby host gets more authority than the server grants |
| Replay and packet tampering | Messages can be replayed, reordered, sped up or changed; session tokens and sequence numbers are not bound to the connection; the server does not limit the rate of actions (see [targets: game clients](../targets/game-clients-and-anti-cheat.md) ("Protocol")) |
| Chat and user-generated content | Names, chat, custom maps, mods and uploads reach other players without filtering, or are rendered or run in their clients with too much power; blocks and reports do not cover every channel (see [46](../dimensions/46-abuse-and-fraud-resistance.md) ("Harassment and unwanted contact")) |
| **Anti-cheat trust boundaries** | The server relies on a verdict or data that the client's anti-cheat reports; anti-cheat components run with more privilege than they need, or accept commands and files that others can supply (see [targets: game clients](../targets/game-clients-and-anti-cheat.md) ("Anti-cheat drivers")) |
