# 4.53 Search, indexing and retrieval

Applies to: full-text search, search engines and indexes, autocomplete, recommendations, vector stores and retrieval for LLM applications, and enterprise search across documents, mail and chat. Apply your own knowledge of the specific search engine and its query language to each row.

| Checkpoint | What counts as a problem |
| --- | --- |
| **Permissions on results** | Results, snippets, highlights, facet counts or suggestions are not filtered by the permissions of the person searching at query time, or are filtered only in the user interface (see [28](../dimensions/28-authorization-and-access-control.md) ("Consistency across entry points")) |
| **Permission changes after indexing** | After access to a document is removed, or the document is deleted, the index, caches, embeddings or stored snippets keep serving it |
| What gets indexed | The indexer runs with more access than the users it serves; private, draft, deleted or secret content goes into a shared index; crawlers follow links into internal systems (see [4.21](4.21-outbound-requests-and-server-side-request-forgery.md)) |
| **Query languages** | User input placed into query syntax (query strings, query languages, filters, scripts) can change the query's structure, reach other indexes or run scripts |
| Enumeration through the index | Counts, suggestions, differences between "no results" and "not allowed", sort order or timing reveal that items exist, or what they contain, to people who cannot see them |
| Tenant and index isolation | Tenants in a shared index or cluster are separated only by a filter the caller can influence; index names and aliases come from values the caller controls |
| Cost of queries | Wildcards, regular expressions, deep pagination, large aggregations and vector searches have no limits (see [20](../dimensions/20-resource-bounds-and-backpressure.md)) |
| Ranking and poisoning | Content an attacker can publish can push itself into other users' results, or into the context retrieved for an LLM, without its origin being marked (see [4.26](4.26-llms-and-tool-calling.md) ("Instructions and external content")) |
