# 4.62 DNS servers and resolvers

Applies to: authoritative DNS servers, recursive resolvers, DNS proxies and forwarders, and dynamic DNS services. Apply your own knowledge of the specific DNS software, record types and DNS extensions to each row.

| Checkpoint | What counts as a problem |
| --- | --- |
| **Cache poisoning defenses** | Transaction IDs or source ports can be predicted; answers are accepted without matching the question; records outside the zone the server was asked about (out of bailiwick) are cached; additional and glue records are trusted too widely (see [4.1](4.1-networking-and-connections.md) ("Self-implemented name resolution")) |
| Open resolver and amplification | Recursion or large answers are offered to any source address; answers are much larger than queries and there is no response rate limit (see [4.28](4.28-tunnels-proxies-and-the-network-data-plane.md) ("Open relay and reflection amplification")) |
| **Zone transfer and dynamic update** | Zone transfers and dynamic updates are allowed by source address alone, without keys; one update key can change any name in the zone; dynamic DNS clients can take over names they do not own |
| DNSSEC validation | Signatures are not validated; a failed validation is treated as unsigned instead of as a failure; the chain of trust or the proof that a name does not exist is checked only in part |
| **Limits on recursion and responses** | Referral chains, alias chains, delegations, queries sent per request, response sizes and validation work have no limits, so one query makes the server do unbounded work or send unbounded traffic (see [facets](../facets/resources-externals-and-observability.md) "Cost asymmetry") |
| **Parsing names and records** | Compression pointers, label lengths, record lengths and record counts from the packet are trusted; a malformed record crashes the server or corrupts the cache (see [4.2](4.2-protocols-and-frame-parsing.md)) |
| Split-horizon leakage | Internal names and addresses reach outside clients through the wrong view, forwarders, errors or zone transfers (see [targets: domains, DNS and mail configuration](../targets/domains-dns-and-mail-configuration.md) ("Leaks in records")) |
