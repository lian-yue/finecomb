# A.9 Ruby

| 检查点 | 什么算问题 |
| --- | --- |
| **反序列化** | `Marshal.load`；不安全的 YAML 加载（Psych 4 起 `YAML.load` 默认安全，`unsafe_load` 不安全） |
| 动态调用 | `send`、`public_send`、`constantize` 的方法名或类名来自外部输入 |
| 命令执行 | `Kernel#open` 的参数以竖线（管道符）开头时会执行命令；反引号、`system` 拼接字符串 |
| **正则锚点** | `^` 和 `$` 匹配的是行首和行尾，校验整个字符串要用 `\A` 和 `\z` |
| 批量赋值 | 请求参数直接赋给模型（见[28](dimensions.md#28-授权与访问控制)「自动字段绑定」） |
| 猴子补丁 | 重新打开核心类，改动影响整个进程 |
| 全局虚拟机锁 | 与 Python 的全局解释器锁同理，不保证复合操作原子 |
