# A.4 C 与 C++

| 检查点 | 什么算问题 |
| --- | --- |
| **未定义行为** | 有符号溢出、越界、释放后使用、重复释放、未初始化读取、空指针解引用、违反严格别名、移位量不小于位宽、数据竞争；编译器可据此删掉溢出检查（如对有符号数写的 `a + b < a`） |
| **缓冲区与字符串** | `strcpy`、`strcat`、`sprintf`、`gets`；`strncpy` 不保证以 NUL 结尾；`snprintf` 返回的是本应写入的长度，要据此判断截断；少算了 NUL 的一个字节 |
| 整数 | 有符号与无符号比较时的隐式转换；`size_t` 减法下溢；分配大小的乘法溢出（`malloc(n * size)`）；`long` 在 LP64 与 LLP64 平台宽度不同；`char` 是否有符号由实现决定 |
| 内存所有权 | 谁负责释放没写明；`p = realloc(p, n)` 失败时原指针丢失；错误路径漏释放 |
| 格式化字符串 | 把外部字符串直接当 `printf` 的格式参数 |
| errno | 只在调用失败时有意义，会被后续调用覆盖；被信号中断的调用返回 `EINTR` |
| 信号 | 信号处理函数里调用非异步信号安全的函数（如 `malloc`、`printf`） |
| 线程 | 非线程安全的函数（`strtok`、`localtime`、`rand`，`getenv` 与 `setenv` 并发）；`volatile` 不提供同步 |
| 清零秘密 | 用 `memset` 清除密钥可能被优化掉，用 `explicit_bzero`、`memset_s` 或平台等价物 |
| 检查后使用 | `access()` 检查之后、`open()` 之前文件被替换 |
| 宏 | 参数被多次求值；缺括号改变优先级 |
| C++ 生命周期 | 容器修改后迭代器失效；返回局部变量的引用；`string_view` 或引用指向临时对象；按引用捕获的 lambda 比被捕获对象活得久 |
| C++ 对象模型 | 基类析构不是虚函数；对象切片；三/五法则；被移动后的对象状态；析构函数抛异常导致终止；`shared_ptr` 循环引用泄漏 |
| 静态初始化顺序 | 跨编译单元的静态对象初始化顺序不确定 |
| 构建加固 | 警告是否开全并视为错误；是否启用栈保护、`_FORTIFY_SOURCE`、PIE、RELRO 等（见[34](dimensions.md#34-运行环境与部署契约)、[36](dimensions.md#36-供应链与制品完整性)） |
| ABI | 结构体布局、对齐、打包、字节序；不同编译器或标准库版本之间的 C++ ABI |
| 异常跨界 | C++ 异常穿过 C 接口或回调 |
