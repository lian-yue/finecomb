# A.8 PHP

| 检查点 | 什么算问题 |
| --- | --- |
| **宽松比较** | `==` 下两个数字形式的字符串按数值比较（如 `"0e123" == "0e456"` 为真）；`in_array`、`array_search` 默认宽松；比较秘密用 `hash_equals` |
| 类型杂耍 | 函数收到数组等意外类型时的行为随版本不同（旧版本常返回 `null` 加警告，PHP 8 多数改为抛 `TypeError`），可能绕过校验 |
| **反序列化** | `unserialize` 处理外部数据会经魔术方法触发 gadget；`phar://` 包装器的元数据反序列化（按版本核对） |
| 文件包含 | `include`、`require` 的路径来自外部输入；远程包含开关 |
| 变量覆盖 | `extract()`、可变变量 `$$` 覆盖已有变量 |
| 整数 | 溢出后自动变成浮点数，精度丢失 |
| 上传 | 上传文件落在可执行目录；只按扩展名或客户端声明的类型判断 |
| 随机数 | `rand`、`mt_rand`、`uniqid` 不是密码学随机源，用 `random_bytes`、`random_int` |
