# A.11 Swift 与 Objective-C

| 检查点 | 什么算问题 |
| --- | --- |
| 强制解包 | 公开输入可触发的 `!`、`try!`、`as!` 崩溃 |
| 整数溢出 | Swift 的算术溢出会在运行时终止进程（`&+` 等运算符才回绕），外部输入可借此制造崩溃 |
| 循环引用 | 闭包强引用 `self` 造成泄漏，需要 `[weak self]` 等 |
| actor 重入 | actor 方法在 `await` 处可被重入，挂起前后的状态不一致（见[18](dimensions.md#18-并发与内存模型)） |
| 主线程 | 界面更新不在主线程；`@MainActor` 标注不全 |
| 归档解码 | 用不要求 `NSSecureCoding` 的方式解档外部数据 |
| Objective-C | 向 `nil` 发消息静默返回零值；格式化字符串来自外部；键值编码的键来自外部输入 |
