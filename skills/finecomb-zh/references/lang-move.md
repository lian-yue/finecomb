# A.15 Move（Aptos、Sui）

| 检查点 | 什么算问题 |
| --- | --- |
| 能力 | 资源类型的 `copy`、`drop`、`store`、`key` 能力是否给得过宽；本应不可复制、不可丢弃的资产被赋予了这些能力 |
| 对象与共享 | Sui 共享对象与自有对象的访问控制；任何人都能传入共享对象时，函数内有没有检查调用者的权限 |
| **共享对象身份** | 函数接收共享对象或池子对象时，是否校验它就是预期的那个实例（按对象 ID 或登记的字段），而不只是类型对得上；攻击者可以自己创建一个同类型的对象传进来 |
| 单例对象 | 应当全局唯一的配置、注册表、池子对象，能否被任何人再创建一份；一次性见证（one-time witness）是否用对 |
| 对象所有权 | Aptos 对象默认允许自由转移；Sui 带 `store` 的对象能被 `public_transfer` 给任何地址；对象被包进别的对象后，原来的访问检查是否仍成立 |
| Aptos 对象引用 | `Object<T>` 只是地址加类型，任何人都能构造；真正的权限在 `ConstructorRef`、`TransferRef`、`ExtendRef`、`DeleteRef` 这类引用里，它们是否被存储、返回或交给了不该拿到的人 |
| 权限凭证 | 权限凭证（capability）对象能否被复制、转移或落到不该拿到的人手里；公开函数有没有无意中返回凭证 |
| 可变引用交给外部 | 把 `&mut` 引用或可变借用的对象传给其它模块的函数后，对方能改写哪些字段 |
| 闪电贷凭证 | 闪电贷用的「烫手山芋」凭证类型不能带 `drop`、`store`；还款函数是否检查数额、币种和凭证对应的池子 |
| 函数值与重入 | Aptos Move 2.2 起支持函数值：调用调用方传入的函数时，它可能回到本模块；运行时对重入的限制范围以链的实现为准，调用前本模块的状态是否已经一致 |
| **算术与移位** | 加减乘除溢出会中止，但左移不检查溢出，高位直接丢掉；手写的溢出检查是否正确（Cetus 2025 年因移位前的溢出检查阈值写错，损失约 2.2 亿美元） |
| 可见性 | `public`、`public(friend)` 或 `public(package)`、`entry` 的选择；本应内部使用的函数被公开 |
| 升级策略 | 包的升级策略与兼容性；升级权限由谁持有 |
| 升级后的旧版本 | Sui 包升级后旧版本仍能被调用，共享对象是否记录版本号并在每个入口检查；升级兼容规则允许的新增函数，会不会给旧对象带来原来没有的权限 |
| 泛型与类型参数 | 类型参数没有约束，调用者能传入非预期的代币或对象类型 |
| 时间与随机数 | 链上时间的来源；随机数模块的正确用法 |
| 随机数的组合与 gas | 使用链上随机数的函数能否被其它合约组合调用：调用方可以在结果不利时中止（Sui 要求只在非公开的 `entry` 函数里用 `Random`，Aptos 要求 `#[randomness]` 标注的入口）；拿到随机结果后，有利和不利两条路径的 gas 消耗不同时，攻击者可用 gas 上限让不利的结果失败回滚 |
