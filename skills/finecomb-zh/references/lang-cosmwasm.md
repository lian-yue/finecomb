# A.17 CosmWasm 与 Cosmos SDK 模块

CosmWasm 合约一般用 Rust 编写，先按[A.5 Rust](lang-rust.md)检查，再看本表。Cosmos SDK 的链模块用 Go 编写，先按[A.1 Go](lang-go.md)检查；节点与共识的通用检查见[4.45](specialties.md#445-区块链节点共识与协议实现)。

| 检查点 | 什么算问题 |
| --- | --- |
| **地址校验** | 地址以 `String` 形式收下后，没有经 `addr_validate` 校验、规范化就存储或比较；大小写不同的同一地址会被当成两个；存储里应保存校验过的 `Addr` |
| **资金与币种** | `info.funds` 是否检查了币种和数额；多个币种时只看了第一个；不需要付款的入口收到资金时，钱会留在合约里 |
| 访问控制与迁移 | 每个执行消息的权限检查；合约管理员能把合约迁移到任意代码，这个管理员是谁；`migrate` 入口是否检查旧版本与新版本 |
| 子消息与回复 | `SubMsg` 的 `reply_on` 设置；子消息失败被 `reply` 处理后，哪些状态回滚、哪些不回滚；`reply` 依赖的临时状态是否可靠 |
| 无界遍历 | 对存储做无界的 `range`，或查询接口不分页；数据增多后超过 gas 上限，合约永久卡住 |
| 整数与 panic | `Uint128` 等类型的普通运算溢出时 panic，中止整笔执行；部分 `cosmwasm-std` 版本里的个别运算在溢出时回绕而不 panic（CWA-2024-002） |
| 未保存的状态 | 改了从存储读出的结构体，却没有写回 |
| **IBC 包处理** | `ibc_packet_receive` 返回错误会让整笔交易中止、中继者无法提交，应改为返回失败的确认；超时和失败确认时是否退回资产；通道和对端端口是否校验 |
| 区块钩子 | 链在每个区块自动调用的合约入口（`sudo` 或链自定义的钩子）里，无界的工作或 panic 会拖慢甚至停住整条链 |
| 模块间记账 | 合约的内部账本与链上银行模块的余额不一致；代币工厂代币的管理员能增发或销毁；合约依赖的链模块回调 |
| 签名者 | SDK 消息的签名者由消息定义里的签名者字段（`cosmos.msg.v1.signer`）决定，是否与处理函数实际使用的地址是同一个 |
| 非确定性 | 链模块在共识路径上遍历 Go 映射、使用浮点、读本机时间、起协程或调用外部服务，各节点结果不同会造成链分叉或停止 |
