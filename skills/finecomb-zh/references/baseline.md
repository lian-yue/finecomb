# 一、建立事实基线

1. **确定范围和依据**：先读适用规范，再读本次相关的定位说明、流程契约和测试矩阵。按[调用与范围解析](scope.md#调用与范围解析)列出目标、排除项和疑似项，以及审查时间、源码或制品的可核对身份、实际配置、平台和构建条件；缺少项目要求的文档按[43](dimensions.md#43-文档一致性)判断。
2. **建立语言与构建清单**：
   - 按扩展名、文件头和构建清单识别每个路径的语言；也要找出嵌在字符串或配置里的语言（SQL、正则、Shell、模板、HTML、表达式）。
   - 列出构建系统与清单文件（如 `go.mod`、`package.json`、`pyproject.toml`、`requirements*.txt`、`Cargo.toml`、`CMakeLists.txt`、`Makefile`、`pom.xml`、`build.gradle`、`*.csproj`、`composer.json`、`Gemfile`），以及声明的语言和运行时版本。
   - 找出每种语言的入口形式：可执行入口、命令行脚本、包导出、路由注册、插件注册、导入时执行的代码。
   - 找出跨语言边界（见[4.32](specialties.md#432-跨语言边界与本地扩展)）。
   - 为每种语言选定[附录 A](languages.md) 的对应表。
3. **建立对象清单**：按[规模自适应](scope.md#规模自适应)读取实现，列出文件职责、公开入口、外部可达的路由与管理入口、后台执行流与自动行为（线程、协程、定时器、终结器、导入或加载时执行的代码、信号处理）、共享状态、不变量和副作用。动态注册、反射、插件和条件编译不能只靠文本引用数判定可达性；非手写内容按项目维护边界处理。
4. **确认上下游**：列实际使用的依赖、调用方、持久化数据和外部系统，区分源码存在、编译包含、部署启用、外部可达。没有部署证据时保留条件，不把默认配置当成线上事实。
5. **判定目标类型**：安全相关目标按[下节](#威胁模型与攻击链)确定资产、攻击者能力和信任边界，再按[历史机制对号](#历史机制对号)选择[专项](specialties.md)。
6. **核对已有证据，选择必要执行**：先检查可复用记录的有效性；需要执行的动作按[审查执行边界](scope.md#审查执行边界)和项目测试策略选择，[七](tools.md)只供选工具。只读审查能静态确定的问题可直接报告，需复现的候选问题只选已授权的最小入口。

## 威胁模型与攻击链

对安全相关目标记录下列事实。缺失的信息写成假设或未验证项，不能为了闭合攻击链补造前提。

| 对象 | 要确认的内容 |
| --- | --- |
| 资产与安全目标 | 数据、凭据、权限、资金、计算资源及服务可用性；谁拥有，哪些读取、变更和中断不允许发生 |
| 攻击者能力 | 未登录者、普通用户、其他租户、低权限运维、被控制的客户端或依赖、**同一台机器上的其他用户或低权限进程**、**本机浏览器里的网页**（可经 localhost 和 DNS 重绑发请求）、提交代码触发持续集成的外部贡献者、上游依赖或插件作者，分别能做什么；凭据、网络位置和用户交互是否为前提 |
| 可控输入 | 请求、消息、文件、已存记录、配置、环境、构建输入、交给解释器执行的源码或规则；哪些字段可直接控制，哪些只能间接影响 |
| 信任边界 | 浏览器到服务、租户之间、服务到数据层、构建到发布、数据到解释器、脚本到宿主、本机低权限进程到高权限服务、一种语言到另一种语言；每次跨界由谁验证身份、内容和权限 |
| 攻击面与阻断点 | 实际启用的入口及各层控制；代理、网关、权限检查、沙箱和隔离策略是否能被绕过，依赖的配置是否已核实 |
| 最终影响 | 从受控输入到违反安全目标的完整路径、所需次数与成本、影响范围、持久性和恢复条件 |

沿「输入来源 → 解码与规范化 → 校验与授权 → 敏感操作 → 状态或外部结果」追踪。重点核对校验对象与最终使用对象是否相同，数据经过存储、队列、回调或二次解析后是否仍受保护。签名通过只说明被签内容通过验证，不代表内容符合业务规则或调用者有权执行。

多个候选问题可以组成攻击链，但每一步都要有可达证据；依赖管理员主动配合、未证明能取得的密钥或不存在的部署配置时，不能报告成普通用户可直接利用。源码审查可参考 [OWASP Secure Code Review](https://cheatsheetseries.owasp.org/cheatsheets/Secure_Code_Review_Cheat_Sheet.html) 的数据流与威胁分析方法。

需要映射外部标准时，记录实际采用的版本、条目和适用理由，例如 [OWASP ASVS](https://owasp.org/www-project-application-security-verification-standard/) 使用带版本的条目标识；本清单的完成不代表取得标准认证。

## 历史机制对号

这张表用于从入口特征找到检查位置，不单独重复判据，也不要求再报一遍相同问题。

| 目标上若存在 | 历史上怎么被打穿 | 落到 |
| --- | --- | --- |
| 按外部数据（参数、已存记录、配置、重定向、webhook、回调地址）去连一个地址 | 出站打到内网 / 云元数据 / 文件协议；DNS 重绑绕过白名单 | [4.21](specialties.md#421-出站请求与服务端请求伪造) |
| 拉起子进程、解释器、eval、把字节反序列化成对象图、加载插件 | 不是「拼进命令」也会执行：环境变量继承、gadget、解码器读本地或出网 | [4.22](specialties.md#422-子进程动态执行与解码器副作用) |
| 解析器会去取外部实体或引用 | 读本地文件、打出站请求 | [4.3](specialties.md#43-解码不受信任的外部数据) |
| cookie / 会话凭证会随浏览器请求自动带上，且该入口会改状态 | 用户被诱使从别的站点发出请求 | [4.14](specialties.md#414-服务端请求处理与中间件)、[4.18](specialties.md#418-用户界面与可访问性) |
| 把外部输入写进跳转地址（`Location`、登录后回跳、通用跳转） | 把人带到钓鱼页，或把令牌送到别处 | [4.18](specialties.md#418-用户界面与可访问性)、[4.5](specialties.md#45-认证会话与令牌) |
| 自己解析 HTTP，或处在两个 HTTP 实现之间（代理、CDN 前） | 长度与分块语义分歧导致前后看到不同请求；未校验的头进了缓存键 | [4.14](specialties.md#414-服务端请求处理与中间件)、[4.2](specialties.md#42-协议与帧解析) |
| 不可信字符串当哈希表 / 字典的键 | 碰撞让单次请求占满 CPU | [20](dimensions.md#20-资源上界与背压)、[27](dimensions.md#27-安全与信任边界) |
| 内部包名在公网注册源也能解析到 | 公网抢注同名包，构建打到假包 | [36](dimensions.md#36-供应链与制品完整性) |
| 日志 / 指标 / 追踪会解释消息里的查找或表达式 | 日志内容变成出站或代码执行 | [4.13](specialties.md#413-日志指标与追踪)、[4.22](specialties.md#422-子进程动态执行与解码器副作用) |
| 将请求对象直接绑定到内部模型，或递归合并外部对象 | 写入未授权字段，或通过原型污染影响其他对象 | [28](dimensions.md#28-授权与访问控制)、[4.3](specialties.md#43-解码不受信任的外部数据) |
| 收到外部回调后更新业务状态 | 合法签名被跨租户、跨操作使用，或旧事件反复生效 | [4.24](specialties.md#424-webhook-与外部事件) |
| 按租约或选主结果写共享数据 | 旧持有者恢复后继续写，覆盖新持有者的结果 | [4.25](specialties.md#425-分布式协调与租约) |
| 大模型读取外部内容后调用工具 | 外部内容改写任务，继而借工具权限读取或修改不该触及的资源 | [4.26](specialties.md#426-大模型与工具调用) |
| 执行外部提供的源码、表达式、模板、查询或规则 | 脚本拿到宿主对象逃出沙箱；内建函数绕过计量，一行代码耗尽内存或 CPU | [4.27](specialties.md#427-解释器编译器与虚拟机)、[20](dimensions.md#20-资源上界与背压) |
| 转发他人流量，或接管系统路由、名字解析 | 自己的流量被自己捕获成环；名字解析或 IPv6 绕过隧道泄漏；被当成开放代理或反射放大器 | [4.28](specialties.md#428-隧道代理与网络数据面) |
| 按规则表放行、拦截、路由或限流 | 后缀、通配边界写错；规则被前面的规则遮住；匹配前没有归一化 | [4.29](specialties.md#429-规则与策略匹配) |
| 直接调用系统接口，或持有原始描述符、句柄 | 描述符号复用后误关别人的；被信号中断的调用被当成失败；内核返回的长度没校验 | [4.30](specialties.md#430-操作系统接口系统调用与描述符) |
| 从 schema、IDL 或模板生成代码 | schema 里的名字注入到生成代码；删掉输入后旧产物残留 | [4.31](specialties.md#431-代码生成器与编译期工具) |
| 两种语言互相调用、共享内存或共享数据定义 | 整数宽度与空值不一致；异常穿过不支持的边界；两侧对内存归属理解不同 | [4.32](specialties.md#432-跨语言边界与本地扩展) |
| 持续集成把事件字段拼进脚本，或在特权上下文运行外部提交 | 外部贡献者拿到发布凭据或写权限 | [4.33](specialties.md#433-构建脚本持续集成与基础设施即代码)、[36](dimensions.md#36-供应链与制品完整性) |
| 发布包给他人安装或链接 | 发布内容夹带秘密；安装时执行代码；破坏性变更没有体现在版本号上 | [4.34](specialties.md#434-可发布的库sdk-与包) |
| 客户端自动更新，或可被其它应用、网页唤起 | 更新包被替换或降级；导出的组件、自定义协议被其它应用或网页调用 | [4.35](specialties.md#435-客户端应用扩展与自动更新) |
| 高权限常驻服务在本机开放控制口 | 本机低权限进程或浏览器网页驱动它执行特权操作 | [4.35](specialties.md#435-客户端应用扩展与自动更新)、[28](dimensions.md#28-授权与访问控制)、[34](dimensions.md#34-运行环境与部署契约) |
| 在固件、驱动或中断上下文运行 | 中断重入破坏共享数据；写闪存时掉电变砖；更新中断后无法启动 | [4.36](specialties.md#436-嵌入式固件与实时约束) |
| 批处理重跑、训练或加载模型文件 | 重跑重复写入；训练与测试数据泄漏；加载模型文件执行了代码 | [4.37](specialties.md#437-数据处理批处理与机器学习)、[4.22](specialties.md#422-子进程动态执行与解码器副作用) |
| 链上合约持有或转移资产 | 重入、价格操纵、抢跑、升级后存储布局冲突 | [4.38](specialties.md#438-智能合约与链上交互) |
| 长期常驻、无人值守运行 | 空闲时热循环；计数回绕；运行中证书过期；休眠唤醒后状态失效 | [45](dimensions.md#45-常驻与长时运行) |
