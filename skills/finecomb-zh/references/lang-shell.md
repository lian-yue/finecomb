# A.10 Shell

| 检查点 | 什么算问题 |
| --- | --- |
| **未加引号的展开** | `$var` 没加引号，会被拆词和通配展开 |
| 出错不中止 | 没有 `set -e`；`set -e` 在条件、管道、`local x=$(cmd)` 等位置不生效；缺 `set -u` 与 `pipefail` |
| **危险删除** | 变量为空时 `rm -rf "$DIR/"` 变成 `rm -rf "/"`；用 `${DIR:?}` 挡住 |
| 参数被当选项 | 以 `-` 开头的文件名被当成选项，用 `--` 分隔 |
| 注入 | `eval`；把外部输入拼进命令，或拼进远程执行的命令串 |
| 临时文件 | 可预测的名字（如 `/tmp/foo.$$`），用 `mktemp` |
| 目录切换 | `cd` 失败后继续在错误的目录里执行 |
| 读取 | `read` 缺 `-r`；`IFS` 被改 |
| 子 shell | 管道里的 `while` 在子 shell 里执行，里面改的变量出来就丢了 |
| 可移植性 | `/bin/sh` 下用了 bash 特性；系统自带的旧版 bash；BSD 与 GNU 工具的参数差异（如 `sed -i`） |
| PATH | 依赖 `PATH` 查找命令，而环境可被调用方控制（见[4.22](specialties.md#422-子进程动态执行与解码器副作用)） |
