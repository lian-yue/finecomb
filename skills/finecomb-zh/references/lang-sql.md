# A.12 SQL 与查询方言

| 检查点 | 什么算问题 |
| --- | --- |
| **空值** | 三值逻辑：`= NULL` 永远不为真；`NOT IN` 的子查询里有 `NULL` 时一行也不返回 |
| 隐式转换 | 字符串与数字比较时隐式转换（如 MySQL 把 `'1abc'` 当成 1），使索引失效或匹配出错 |
| 排序规则 | 大小写与重音是否敏感；尾部空格是否参与比较；数据库唯一约束与应用层判断不一致 |
| 非严格模式 | 超长字符串被截断、非法值被改成默认值而不报错 |
| 默认隔离级别 | 各数据库默认值不同（如 MySQL InnoDB 为可重复读，PostgreSQL 为读已提交） |
| 结果顺序 | 没有 `ORDER BY` 时顺序不保证，`LIMIT` 分页结果不稳定 |
| 时间类型 | 带时区与不带时区的类型；会话时区对读写的影响 |
| 自增与序列 | 自增值有间隙、回滚不回收；对外暴露后可被枚举 |
