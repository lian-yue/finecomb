# A.18 Cairo（Starknet）

一层与二层之间的消息另见[4.42](specialties.md#442-跨链桥与跨链消息)。

| 检查点 | 什么算问题 |
| --- | --- |
| **`felt252` 算术** | `felt252` 在一个大素数上回绕，不检查溢出，减法也可能得到很大的数；比较大小的语义与普通整数不同；金额和计数是否改用 `u256`、`u128` 等带检查的整数类型 |
| **一层消息来源** | `#[l1_handler]` 函数是否检查 `from_address` 就是预期的一层合约；否则任何一层合约都能发来消息 |
| 一层到二层的地址 | 以太坊地址与 Starknet 地址的取值范围不同；地址转换是否校验范围与零地址 |
| 一层到二层消息失败 | 一层发往二层的消息在二层执行失败后不会自动重试；一层合约是否提供了取消消息、退回资产的流程 |
| 签名重放 | 账户合约和链下签名是否包含链标识、随机数与合约地址 |
| 存储变量名冲突 | 存储地址由变量名的哈希得出；组件之间、升级前后同名的变量会落到同一个槽位 |
| 升级 | 调用 `replace_class_syscall` 换代码的权限；新旧类的存储是否兼容 |
